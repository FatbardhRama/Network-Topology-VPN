# Enterprise Network Topology & VPN Simulation

## Overview

This project demonstrates the design and implementation of a small enterprise network infrastructure using Cisco Packet Tracer.

The network simulates a company environment with multiple departments, VLAN segmentation, inter-VLAN routing, security policies and secure communication between headquarters and a branch office through a site-to-site VPN.

---

## Features

- VLAN segmentation
- Inter-VLAN Routing (Router-on-a-Stick)
- Static Routing
- DHCP Configuration
- ACL Security Policies
- Site-to-Site VPN
- WAN Connectivity Testing
- Network Verification and Troubleshooting

---

## Network Structure

The topology includes:

- HQ (Headquarters)
- Branch Office
- Routers and Switches
- Multiple VLANs
- WAN connection between locations

### VLANs

| VLAN | Department | Network |
|------|------|------|
| 10 | IT | 192.168.10.0/24 |
| 20 | Finance | 192.168.20.0/24 |
| 30 | HR | 192.168.30.0/24 |
| 40 | Admin | 192.168.40.0/24 |
